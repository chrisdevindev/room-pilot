# Tradução / Translation

Os textos do aplicativo ficam em `src/Localization/pt-BR.json` e `en-US.json`. O executável incorpora os catálogos; não precisa baixar traduções nem acessar um serviço externo. Português e inglês incluem painel, configuração, menu da bandeja, atalhos, login, estados e mensagens de erro.

Application text lives in `src/Localization/pt-BR.json` and `en-US.json`. Catalogs are embedded in the executable, with no network translation service.

## Alterar textos / Editing text

- Use chaves descritivas, como `action.save` ou `error.connection`.
- Use `L10n.Text("chave")` para texto simples e `L10n.Format("chave", argumentos)` para frases parametrizadas.
- Preserve `{0}`, `{1}` e outros parâmetros em todos os idiomas. Traduza a frase inteira, sem concatenar trechos traduzidos.
- Não traduza nomes personalizados, identificadores de dispositivos, comandos da CLI, nomes de campos JSON do protocolo, códigos de erro ou domínios Amazon.
- `language.name` contém o nome nativo do idioma, mostrado no seletor.

Use descriptive keys, translate complete sentences, and keep the same formatting placeholders in every catalog. Never translate user device names, identifiers, protocol fields, CLI action tokens, error codes, or Amazon domains.

## Acrescentar idioma / Adding a language

1. Copie `en-US.json` para um arquivo com um código de cultura válido do .NET, como `es-ES.json`.
2. Traduza os valores, incluindo `language.name`, mantendo as chaves e parâmetros.
3. Execute `build.ps1`. Os scripts de compilação incorporam todos os JSON da pasta e o seletor descobre os catálogos automaticamente.
4. Atualize a lista de arquivos públicos em `public-files.txt` e confira a interface, os testes e os pacotes.

Copy the English catalog to a valid .NET culture name, translate all values, build, update the public manifest, and review layout. No new translation framework or selector code is needed. Automatic system-language detection currently selects Portuguese for `pt-*` cultures and English otherwise; additional languages can be selected explicitly.

## Preferência e compatibilidade / Preference and compatibility

A preferência `AppConfig.Language` usa códigos como `pt-BR` e `en-US`. O formato da configuração é a versão 3; versões 1 e 2 recebem português ao serem carregadas, preservando o comportamento anterior. Novas configurações usam o idioma inicial detectado. A troca só é aplicada ao salvar a configuração, recriando cartões e menu e atualizando os textos fixos. Os nomes dos aparelhos não mudam.

`--language` é uma substituição temporária. Não grava a preferência. A região da conta Alexa é independente do idioma. A página de login solicita a cultura selecionada à Amazon, mas o conteúdo da página é controlado pela própria Amazon.

The saved language is independent of the Alexa account region. Older configurations retain Portuguese. A temporary `--language` override does not save settings. Amazon controls the contents of its own sign-in page.

## Verificação / Verification

Os testes verificam igualdade das chaves, parâmetros e valores não vazios, leitura dos recursos incorporados, persistência da preferência, textos em ambos os idiomas, atualização dos cartões, mensagens em tarefas assíncronas e preservação dos identificadores e da sessão. Antes de distribuir, confira também visualmente os textos mais longos.

Tests check catalog parity, placeholders, embedded resources, persistence, both languages, dashboard updates, asynchronous messages, and preservation of device identifiers and sessions. Also review long text visually before distributing.
